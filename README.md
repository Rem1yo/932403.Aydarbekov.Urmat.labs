# Лабораторная работа 1. Основы HTML и структура веб-страницы

Цель: освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, ссылками и изображениями.

Вариант 2: «Путешественник», цвета бежевый и оранжевый.

## Что сделано

Страница «О себе» в файле `index.html`. На ней есть:

- `header` - шапка с аватаром, заголовком и моим именем
- `main` - основной контент
- секция «Навыки» - маркированный список `ul`, внутри него вложенный список языков
- секция «Проекты» - нумерованный список `ol` со странами, где я был, и куда хочу поехать
- `aside` - любимое место (Иссык-Куль)
- `footer` - копирайт и год
- картинка-аватар с атрибутами `src`, `alt`, `width`, `height`
- форма обратной связи: имя (`type="text"`), email (`type="email"`), сообщение (`textarea`) и кнопка. У всех полей есть `name` и `placeholder`

Стили написаны в теге `style` внутри `index.html`. Контент и боковая панель стоят в две колонки через flex, на телефоне панель уходит вниз.

## Файлы

- `index.html` - сама страница
- `images/avatar.svg` - аватар

## Как открыть

Просто открыть `index.html` в браузере.

## Проверка

Проверил страницу через [W3C Validator](https://validator.w3.org/nu/), ошибок нет.
