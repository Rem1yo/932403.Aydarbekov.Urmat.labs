# Лабораторная работа 5. DOM и взаимодействие с элементами страницы

Цель: научиться работать с деревом DOM, находить элементы, менять содержимое и стили, сохранять состояние страницы между перезагрузками через localStorage.

Вариант 2: «Путешественник» (управление навыками для поездок).

Страница взята из лабораторной 4. Скрипт с отчётом по маршруту (`prompt` и `alert` при загрузке) остался в ветке `lab4`, здесь в `script.js` только работа с DOM, иначе окно с вопросом об имени выскакивало бы при каждой загрузке.

## Что есть на странице

Над секцией «Навыки» стоит панель из четырёх кнопок, ниже карточек навыков добавлен список `ul#skills-list`.

- «Добавить навык» - спрашивает название через `prompt`, создаёт `li` с текстом и кнопкой «Удалить» и добавляет его в `ul` через `appendChild`. Кнопка «Удалить» убирает именно свой пункт. На «Отмену» и пустую строку страница не реагирует (на пустую строку выводится `alert`).
- «Очистить навыки» - находит все `li` через `querySelectorAll` и в цикле вызывает `remove()` у каждого. Если список уже пуст, показывает `alert` «Навыки уже удалены».
- «Скрыть список навыков» - добавляет секции навыков класс `invisible` (`display: none`), повторное нажатие убирает его, текст кнопки меняется на «Показать список навыков».
- «Тёмная тема» - добавляет или убирает класс `dark` у `body`. В `style.css` этот класс переопределяет переменные цветов.

## Поиск элементов

- `getElementById` - кнопки и список (функция `findById`)
- `querySelector` - `body` и секция `#skills` (функция `findOne`)
- `querySelectorAll` - пункты списка при очистке и при сохранении

## Обработка ошибок

`findById` и `findOne` пишут в консоль «Элемент не найден: [id/селектор]» и возвращают `null`, а функция, которой нужен этот элемент, сразу завершается. Чтение и запись в localStorage обёрнуты в `try/catch`: если данные повреждены или хранилище недоступно, страница не падает, а берёт значения по умолчанию.

## localStorage

- `travel-skills` - массив названий навыков в JSON, обновляется при каждом добавлении, удалении и очистке
- `travel-theme` - `"light"` или `"dark"`, обновляется при переключении темы

При загрузке страница читает оба ключа. Если ключа `travel-skills` нет, показываются четыре навыка по умолчанию. Пустой массив считается сохранённым состоянием (навыки очистили), поэтому после перезагрузки список остаётся пустым. Скрытие списка не сохраняется, в задании требуется только список и тема.

Название навыка вставляется через `textContent`, а не `innerHTML`, потому что его вводит пользователь.

## Контрастность

В тёмной теме все пары текста и фона не ниже 4.5:1 (формула WCAG). Самая слабая пара - белый текст на оранжевом `#b35a12`, 4.79:1.

## Как проверял

В браузере:

1. Добавил навык с пробелами по краям и тегом `<b>` в названии: пробелы обрезались, тег показался текстом.
2. Удалил второй пункт списка, перезагрузил страницу: остался список без него, добавленный навык на месте.
3. Включил тёмную тему, перезагрузил: тема восстановилась.
4. Нажал «Очистить навыки», перезагрузил: список пуст. Нажал ещё раз: появился `alert` «Навыки уже удалены».
5. Нажал «Отмена» в `prompt` и ввёл пустую строку: список не изменился.
6. Удалил из DOM список и секцию навыков и нажал кнопки: в консоли появились сообщения «Элемент не найден: #skills-list» и «Элемент не найден: #skills», ошибок нет.
7. На ширине 375px горизонтальной прокрутки нет.

HTML проверен в [W3C Validator](https://validator.w3.org/nu/): ошибок и предупреждений нет. Остались 4 информационных замечания про `article` без заголовка, они относятся к карточкам навыков из лабораторной 3. CSS проверен в [W3C CSS Validator](https://jigsaw.w3.org/css-validator/): ошибок нет.
