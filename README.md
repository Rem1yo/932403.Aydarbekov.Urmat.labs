# Лабораторная работа 2. Базовые и продвинутые возможности CSS

Цель: научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

Вариант 2: «Путешественник», липкая навигация и акцент на hover.

Страница взята из лабораторной 1 и оформлена заново через внешний файл стилей.

## Три способа подключения стилей

1. Внешний файл `style.css`, в нём основная часть стилей.
2. Внутренний блок `style` в `head` файла `index.html`: там стили секции «Проекты», список стран разбит на две колонки через `column-count` и `column-gap`.
3. Inline-стиль: у кнопки отправки формы прямо в HTML прописан `style="font-size: 16px;"`.

## Переменные в :root

В `style.css` в блоке `:root` заданы цвета (`--color-bg`, `--color-surface`, `--color-text`, `--color-accent`, `--color-heading`, `--color-muted`, `--color-border`) и шрифты (`--font-main`, `--font-title`). Основной цвет бежевый, акцент оранжевый, как в варианте.

## Позиционирование

- `static` - явно прописан заголовку `h2` в секции «Проекты», это значение по умолчанию
- `relative` - у карточек `.block`, чтобы внутри можно было ставить элементы по краям
- `absolute` - бейдж «Топ-1» в правом верхнем углу карточки «Любимое место»
- `sticky` - навигация, она прилипает к верху экрана при прокрутке (`top: 0`)

## Состояния элементов

- `:hover` - ссылки в навигации плавно меняют цвет на оранжевый, под ними появляется тонкая линия через псевдоэлемент `::after`; у кнопки темнеет фон
- `:active` - ссылка становится темнее, кнопка сдвигается вниз на 2px
- `:focus` - у полей формы рамка становится оранжевой и меняется фон, у кнопки и ссылок появляется обводка
- `:visited` - посещённые ссылки в боковой панели становятся фиолетовыми

## Контрастность

Цвета подобраны так, чтобы контраст текста был не ниже 4.5:1. Палитра из первой лабы это требование не проходила (белый текст на оранжевой шапке давал всего 2.71:1), поэтому оранжевый стал темнее: `#b35a12` для акцента и `#a8530f` для заголовков. Проверял формулой контраста WCAG, худшая пара на странице сейчас 4.61:1.
