# Лабораторная работа №1. Основы HTML и структура веб-страницы

**Цель:** освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, ссылками и изображениями.

**Вариант 2 — «Путешественник».** Цветовая гамма: бежево-оранжевая.

## Что на странице

Страница «О себе» (`index.html`) состоит из семантических блоков:

| Тег | Содержимое |
|-----|------------|
| `<header>` | аватар, заголовок страницы, имя и фамилия |
| `<main>` | основной контент: две секции и форма |
| `<section id="skills">` | «Навыки» — маркированный список (`<ul>`) навыков, полезных в путешествиях, с вложенным списком языков |
| `<section id="projects">` | «Проекты» — нумерованный список (`<ol>`): страны, где я был, и страны, которые хочу посетить |
| `<aside>` | боковая панель: любимое место — озеро Иссык-Куль |
| `<footer>` | копирайт и год |

Изображение подключено с атрибутами `src`, `alt`, `width`, `height`.

Форма обратной связи содержит поля «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`<textarea>`) и кнопку отправки. У всех полей есть `name` и `placeholder`, каждое поле связано со своим `<label>` через `for`/`id`.

Цвета заданы небольшим блоком `<style>` в `<head>`: бежевый фон `#f5ebdc`, оранжевые акценты `#e8833a` и `#c4621b`, тёмно-коричневый текст `#4a3222`. Основной контент и боковая панель стоят рядом (flexbox), на узких экранах панель уходит под контент.

## Структура

```
lab1/
├── index.html         # страница «О себе»
├── images/
│   └── avatar.svg     # аватар с инициалами
└── README.md
```

## Как открыть

Открыть `index.html` в любом браузере. Сборка и сервер не нужны.

## Проверка

Разметка проверена в [W3C Markup Validation Service](https://validator.w3.org/nu/) — ошибок и предупреждений нет.
